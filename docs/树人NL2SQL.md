


# NL2SQl

## 需求描述

- 需要开发一个excel检索系统
- 客户提供excel表，包含多年的招生信息，有年份，省份，最高数，最低分，平均分，位次号，类别，专业 6个维度
- 用户输入自然语言，需要转换为查询语言，能够对上述的一个或者多个维度进行查询

## 功能点
- 加载excel 表中内容，并存储到pandas中
- 对用户的查询语句如："江苏物理生物地理478分希望大吗", 要能通过LLM转换为pandas查询过滤语句，此处需要设计有效的prompt
- 该过滤语句要能够用代码执行，过滤出的excel信息要能够回答用户问题

## 执行
- 请充分理解上面的需求，并实现上述功能点


## 示例

- 针对问题:【老师，我浙江高考分468分，选科史地生，次位206469，想二段志愿填报您校的本科专业（如生物工程、物联网工程、环境生态工程等），问有入取可能吗？】，请转换为pandas查询语言，用于查询相关的信息，并不需要给出具体答案
- 只输出查询字符串，此字符串可以用eval进行运算，不要输出任何其他信息
- 给出具体技术实现
