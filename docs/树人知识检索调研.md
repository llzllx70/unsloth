# 在SFT训练的基础上进行GRPO训练

## 训练结果

### 好的方面

- 回答结果正确
- 中间提取的分数和位次也正确

### 不好的方面

- 内容过长, 骗取奖励
- 中间对比过程不对

### 结论

- 从训练日志看: reward 持续上升(4->8)，可知模型在提升
- 从返回结果看: 原奖励函数中的正向奖励在不停的命中，导致有多个相似词汇重复出现：如高于和大于，不能和不可以
- 说明reward函数的设置对训练效果的很重要的影响
